A3自有名单

四件事，没有一件是花招。

  1. 激励

    不给点什么，没人会留下邮箱，给什么由艺人决定。先用一个试，看收集了多少，不管用就换激励，不换系统。

  2. 许可

    收集时要有明确同意，并且留有记录。没有许可的名单不是资产，是麻烦。

  3. 城市

    每个联系人都带着城市录入。没有地理信息，名单只能用来群发邮件，别的什么都做不了。

  4. 留下的东西

    名单是您的，在您名下，用您的账号。哪天我们不再合作，您直接带走。

A4有依据的演出邀约

一个每月 12,000 名听众、一年大约十五场演出的项目

我们会看什么
根据平台已经显示的数据看听众来自哪里，有哪些未发布的素材可以当激励，以及现在有哪些自有联系人，通常是零。
我们会找什么
把借来的受众中的一小部分转成自有名单，看看有人收听的城市和一直在演出的城市是否吻合。
能打开什么
如果在一个从没去演过的城市出现了 120 个自有联系人，那就是和推广方之间一场以前不存在的对话。

我们会衡量的：每次活动收集到多少自有联系人，来自哪些城市。

B1唱片箱

八件东西，像翻唱片一样一张张看。

要实施的内容。前三个是行业专属，后五个是基础，基础一定会做，撑起前三个。

  1. 01Fan Map

    在您的自有名单上画出的地图，显示真正的人在哪里。

  2. 02Booking Radar

    把 Fan Map 和收听信号、地区、场地以及推广方交叉对比，看清哪些市场值得做、和谁一起做。

  3. 03Track Finder

    输入一首参考曲，出来相似的歌。是排 set 和找音乐用的工作工具。

  4. 04CRM

    在您现有的基础上做。如果没有，就按项目的真实流程搭起来。

  5. 05整理好的数据库

    每人一行，而不是像通常那样按互动记录。

  6. 06自己的电子报

    用您自己的名单抢先宣布，不用花钱给平台才能联系到自己的观众。

  7. 07自己的网站，可自行编辑

    项目网站，带演出日期和作品目录，自动更新。

  8. 08会接待的聊天机器人

    回答常见问题，不知道的就连同完整对话转出去。

把光标移到书脊上就能抽出唱片，也可以用键盘方向键翻看唱片箱。

B2AUDIT

七个领域，再加上行业专属。

Audit 看的不是一首歌，而是整个项目。一份 15 到 25 分钟的引导问卷，半小时一对一通话，路线图就从这里出来。

  • 受众

    有多少人关注您，其中又有多少人您明天就能直接联系、不用依赖任何人。

  • 演出邀约

    演出是怎么来的，对每个城市、每个推广方了解多少。

  • 数据

    您的人真正在哪里听，和您演出的地方是否吻合。

  • 内容

    发布什么，谁来做，花多少时间。

  • 接待

    粉丝和推广方都往同一个地方发消息，没有分开。

  • 团队

    经纪团队用现有工具能解决什么。

  • 工具

    现在用什么工作，因为没有系统，哪些事还在手工做。
